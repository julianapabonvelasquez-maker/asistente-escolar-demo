# Asistente Escolar IA V0.0

## Descripción

Prototipo de aplicación web para ayudar a padres
y cuidadores a organizar las actividades escolares
de sus hijos.

Su propósito es facilitar la planificación semanal
de tareas, exámenes y fechas de entrega.

La aplicación NO resuelve tareas ni presenta
evaluaciones en nombre de los estudiantes.

## Funciones de la demostración

- Consultar actividades por estudiante.
- Visualizar exámenes y entregas.
- Organizar una agenda semanal.
- Mostrar la sección de origen de cada actividad.

## Tecnologías

- Python
- Streamlit
- Pandas

## Datos y privacidad

Esta demostración utiliza exclusivamente datos
ficticios de dos estudiantes de prueba.

No contiene información personal de menores,
contraseñas escolares ni datos reales de Phidias.

Para ejecutar la demostración:

1. Instalar las dependencias de requirements.txt.
2. Ejecutar: streamlit run app.py
